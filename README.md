# 给我滚

基于 **Godot 4.6**（`Jolt Physics` + `GL Compatibility`）开发的 3D 真实物理重力倾斜肉鸽闯关游戏。

玩家仅需操控**左 / 右两个按键**偏转物理世界的等效重力场（默认 `±35°`），在 **30 秒生死倒计时**内借助斜坡、跳台、缓冲桩与连环爆炸冲破怪物与路障防线抵达终点。每过一关赛道长度递增，玩家通过抽取**底盘常数、物理转化器、规则与乘区放大器**三层原子强化卡，利用真实动量（$P = m v$）与动能（$E_k = \frac{1}{2} m v^2$）公式组合涌现出 `1 + 1 > 2` 的超音速流派。

---

## 核心特色

1. **极简双键操控 + 防挥鞭等效侧倾重力**
   - 赛道自带 `11°` 基础下坡重力分力自动推球向前；按住 `A / ←` 或 `D / →` 平滑偏转 `PhysicsServer3D` 全局三维重力矢量，配合追尾相机反向横滚与动态速度 FOV，兼顾真实侧滑物理与丝滑手感。
   - 全程无复杂血条，**时间即生命**：坠崖不即死（触发 `1.2 秒` 时空拉回惩罚，期间倒计时继续流逝），唯超时归零判负。
2. **程序化积木赛道拼接（Chunk Generator）**
   - 赛道总长度随关数按公式严格递增，由 **6 类模块化 3D 区块**随机拼接：宽体极速直道、无护栏高收益窄桥、风险收益双岔路、断桥飞跃大跳台、弹珠缓冲走廊、漏斗混战检定区（第 3 关起解锁）。
   - 内置 **7 类动量交互实体**：脆木箱、粘液减速带、巡逻弹性史莱姆、重甲盾卫、涡轮加速带、高弹缓冲桩、不稳定连环炸药桶。
3. **可涌现的物理乘数构筑底座（Emergent Synergy Engine）**
   - **双乘区属性表 (`StatSheet`)**：所有球体物理参数统一按 `(Base + FlatAdd) × Π(1 + Mult)` 实时重算并钳制安全上下限。
   - **三层正交词条管线 (`PhysicsSynergyBus`)**：首批内置 **12 张正交原子卡**，零硬编码套装特判，仅凭物理公式与事件钩子即可自然涌现出不同跑法：
     - **重锤跳蛙流**：`实心钨核` + `高弹硫化胶` + `震地折射器`（落地垂直冲量折射前向爆发 + 环形震荡波）
     - **Z 字撞墙闪电漂移流**：`侧倾尾流喷口` + `矢量折射核心`（撞护栏法线冲量强制折射向前） + `动量过载引擎`（最高叠 20 层达 `3.4x` 冲量乘区）
     - **连环肉弹火箭流**：`巨球力场` + `动能殉爆炉`（按 $\sqrt{E_k}$ 引爆气浪） + `顺风帆装甲`

## 操控方式

| 阶段 | 按键 / 操作 | 功能 |
| :--- | :--- | :--- |
| **赛道冲刺中** | `A` / `←`（或鼠标按住左半屏） | 向左倾斜世界重力 |
| **赛道冲刺中** | `D` / `→`（或鼠标按住右半屏） | 向右倾斜世界重力 |
| **过关三选一界面** | `A`/`D` 或 `←`/`→` + `空格`/`回车`（或 `1`/`2`/`3`、鼠标点击） | 选择并装载 1 项物理原子强化 |
| **超时结算界面** | `空格` / `回车` / `R`（或点击按钮） | 立即开启新一局挑战 |

## 本地运行与自动化测试

### 1. 使用 Godot 编辑器直接游玩
1. 安装 **Godot Engine 4.6+**（标准版，内置 `Jolt Physics` 与 `GL Compatibility` 渲染器）。
2. 打开 Godot 项目管理器，导入本仓库根目录下的 `project.godot`。
3. 按下 **`F5`**（运行项目）即可直接开始游玩。

### 2. 命令行运行完整自动化测试套件
项目内置基于 Godot Headless 的单元测试与 3D 物理仿真集成测试（覆盖双乘区计算、关卡长度曲线、12 张原子卡涌现乘数、安全递归上限 `chain_depth <= 3`、赛道无缝拼接以及端到端 3D 构筑对比仿真）：

```bash
./scripts/test.sh
```

## 如何扩展新词条与新赛道区块

底层采用完全数据驱动的插件式设计，无需在 `PlayerBall3D` 中堆砌 `if-else`：

- **新增一张强化卡**：只需在 `src/upgrades/upgrade_catalog.gd` 中注册一个新的 `UpgradeDefinition`，链式声明 `.with_flat(...)`、`.with_mult(...)`、`.with_flag(...)` 或 `.with_hook("on_smash_target", callback)` 即可自动进入加权随机抽卡池。
- **新增一种赛道积木块**：在 `src/track/track_chunk_base.gd` 中添加新的几何拼接分支，并在 `src/track/track_generator_3d.gd` 的区块池与实体槽位生成器中注册名称即可。
- **完整设计规范与实现计划**：
  - 设计规格书：`docs/superpowers/specs/2026-11-25-gravity-tilt-roguelike-design.md`
  - 实现计划书：`docs/superpowers/plans/2026-11-25-gravity-tilt-roguelike.md`
