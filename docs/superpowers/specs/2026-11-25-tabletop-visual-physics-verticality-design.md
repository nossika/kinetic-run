# 《给我滚》桌面玩具工坊视觉升级、物理去眩晕与立体腾空玩法设计文档

- **日期**：2026-11-25
- **前置架构**：`docs/superpowers/specs/2026-11-25-gravity-tilt-roguelike-design.md`
- **引擎与平台**：Godot 4.x（`gl_compatibility` 渲染器，Jolt Physics 3D，兼容桌面端原生与 Web HTML5 导出）
- **核心目标**：
  1. **防眩晕操控与物理统一**：固定跑道与镜头水平线，采用**全局垂直向下重力 + 真实 `11°` 下坡木质滑道 + 按住即推/松手即停的小球侧向推力**，辅以直观的推力方向标识；
  2. **0.2 秒属性直觉识别体系**：统一为**明亮桌面玩具轨道风（Tabletop Marble Run）**，利用 `gpt-image` 生成无缝材质贴图，让**软/硬材质、物体真实重量（`500g` ~ `20kg` 钢印小字）、跑道锁死固定件（铆钉法兰底座）**一眼可辨；
  3. **高度方向立体玩法与攻防博弈**：新增波浪起伏滑道、侧边可选小斜坡、桌面弹簧弹射板、悬空加速加时星环，并在空中航道布置少量**漂浮障碍物**防止无脑走空中过关。

## 1. 模块一：真实下坡物理、防眩晕镜头与侧推方向标识

### 1.1 全局统一垂直重力与真实 `11°` 下坡滑道
- **唯一全局重力**：`PhysicsServer3D` 空间重力恒定为纯垂直向下 `Vector3(0.0, -22.0, 0.0)`，不再随玩家输入发生空间偏转。主角球与桌面上所有活动刚体共享同一套真实垂直重力场。
- **真实倾斜滑道（`TRACK_SLOPE_PITCH_DEG = -11.0°`）**：
  - `TrackGenerator3D` 下的赛道根节点 `_track_root`（`GeneratedTrack`）在世界空间绕 `+X` 轴固定旋转 `-11.0°`（使前向 `-Z` 自然向低处延伸，坡降比 $\sin 11^\circ \approx 0.1908$）。
  - **主角球自然滚落**：球体无静摩擦锁死，受垂直重力的坡面切向分力自动向前加速滚动；为抵消实心球转动惯量分流（$\frac{5}{7} g \sin\theta$）使节奏与 30 秒关卡预算完全一致，保留球体沿坡面 `-Z` 方向的轻量基础滚动补偿力 `3.2 * mass * forward_drive_mult`。
  - **桌面活动重物稳驻坡面**：所有放置在跑道上的非固定 `RigidBody3D` 作为 `_track_root` 的子节点生成，初始姿态与 `11°` 坡面平行贴合，并统一配置高摩擦系数物理材质（`friction = 0.88`，远大于坡面自滑临界值 $\tan 11^\circ \approx 0.194$）及适度睡眠/角阻尼。未被撞击或气浪波及时，所有重物稳稳停留在坡面上绝不自行溜坡；一旦被撞击破除静摩擦，即按真实质量顺坡翻滚、互撞或坠落悬崖。
- **赛道局部坐标换算接口**：
  - `TrackGenerator3D` 提供 `world_to_track_local(world_pos: Vector3) -> Vector3` 与 `track_local_to_world(local_pos: Vector3) -> Vector3`。
  - `PlayerBall3D` 的**离地腾空高度**（`local_pos.y - current_radius`）、**坠崖拉回判定**（`local_pos.y < -FALL_Y_OFFSET`）、**安全复位锚点**以及 `GameWorld3D` 的**冲线进度计算**（`-local_pos.z / total_length`）全部基于赛道局部坐标执行，确保任意长度的下坡赛道物理与逻辑严丝合缝。

### 1.2 按住即推、松手即停的小球侧向推力
- **侧推控制器（`LateralThrustController`，演进替换原 `GravityTiltController`）**：
  - 读取左（`A` / `Left` / 屏幕左半区按住）与右（`D` / `Right` / 屏幕右半区按住）输入，输出瞬时推力轴 `thrust_axis ∈ [-1.0, 0.0, +1.0]`。
  - **按住期间**：每物理帧仅对 `PlayerBall3D` 施加水平侧向推力 `F_x = thrust_axis * mass * BASE_LATERAL_ACCEL * tilt_lateral_force_mult`（`BASE_LATERAL_ACCEL = 20.0 m/s²`，腾空期间保留 `0.65` 倍空中微调系数，允许玩家在半空微调落点绕开空中路障或穿环）。
  - **松手瞬间**：同一物理帧 `thrust_axis` 立即归零，不再有任何残余偏转重力；同时对球体横向速度 `linear_velocity.x` 施加温和的止滑阻尼（地面横向阻尼系数 `2.2`），使变道收放干脆跟手。
- **词条无缝适配**：
  - 原 `tail_thruster`（「侧倾尾流喷口」）升级为**「侧喷尾流喷口」**：属性修饰改为 `tilt_lateral_force_mult` 乘算 `+35%`；钩子逻辑改为当玩家按住左/右侧推（`absf(thrust_axis) > 0.1`）持续变道时，每秒按当前横向速度 `absf(lateral_speed)` 转化额外前向推进冲量。

### 1.3 防眩晕追尾相机与双重推力方向标识
- **零横滚稳定跟拍（`ChaseCamera3D`）**：
  - `ROLL_FACTOR` 置为 `0.0`，相机 `rotation_degrees.z` 恒定为 `0.0°`，彻底消除画面左右摇摆导致的眩晕。
  - 相机俯仰角固定为 `-28.0°`（适配 `-11°` 下坡滑道，既能看清脚下球体标重与推力箭头，又能远眺前方高空星环与漂浮路障），保留基于速度的柔和动态 FOV（`64° ~ 84°`）与受控碰撞震屏。
- **明亮桌面工坊日光环境（`GameWorld3D._setup_lighting_and_sky`）**：
  - 背景升级为明亮柔和的工坊浅暖灰蓝天光（`ProceduralSkyMaterial` / 柔和暖白平行主光 + 充足漫反射环境光），开启柔和阴影，全面衬托木纹、金属砝码与半透明果冻质感。
- **双重推力方向标识**：
  1. **球侧 3D 随动推力环（`PlayerBall3D` 内置非自转子节点 `_hud_ring_root`）**：每帧保持水平姿态跟随球心。按住左推时，球体左侧亮起醒目的青蓝色半透明亚克力方向箭头 `◀`，右侧喷出三道短促白色气流脉冲条；按住右推时镜像显示 `▶`；松开按键立即平滑消隐。
  2. **HUD 推力状态指示器 + 球重铭牌**：`HudOverlay` 操作栏与速度面板实时高亮当前 `[ ◀ 左推 ]` / `[ 右推 ▶ ]` 状态，并在主角球上方/侧下角贴合显示实时球重徽标（如 `● 1.5kg`）。

## 2. 模块二：桌面玩具轨道统一视觉体系与属性直觉识别

围绕“**一眼看懂软硬材质、一眼看清物体轻重、一眼分清能否撞动**”三大目标，建立统一的四维视觉语法。

### 2.1 `gpt-image` 风格统一美术贴图资产表
利用项目已配置的 `.agents/skills/gpt-image/scripts/generate.py` 生成 6 张 `1024x1024` 高清风格化无缝贴图，存放于 `assets/textures/`：
1. `track_beechwood.png`：明亮温暖的浅色天然榉木拼接轨道板纹理（用于主跑道地板与波浪坡）。
2. `crate_balsa_wood.png`：干净的浅色轻木/积木颗粒纹理，带柔和木工纹理细节（用于 `500g` 与 `2.5kg` 积木箱）。
3. `metal_cast_iron.png`：深灰锤纹铸铁金属纹理（用于 `20kg` 重型砝码、`12kg` 空中磁浮铁块及固定法兰底盘）。
4. `anchor_hazard_stripe.png`：桌面工坊风黑黄斜纹机械警示贴图（用于固定刚体锁死底座外圈）。
5. `barrel_retro_hazard.png`：复古发条玩具风红白条纹爆竹铁皮贴图（用于 `1.5kg` 易爆铁桶）。
6. `jelly_bubble_soft.png`：清透果冻气泡柔光纹理（用于软弹果冻怪与地面减速胶水滩）。

> **Headless 测试兼容保障**：所有贴图加载与网格装配统一通过升级版 `MaterialLibrary` / `RenderHelper` 封装；在 `--headless` 自动化测试模式下跳过 GPU 纹理/网格开销，确保全部单元测试毫秒级无报错运行。

### 2.2 软材质 vs 硬材质视觉规范
- **硬材质（Hard / Rigid）**：
  - **轮廓**：清晰几何切面、金属圆柱或方正积木块。
  - **材质参数**：金属类 `metallic = 0.72 ~ 0.85, roughness = 0.25 ~ 0.38`；硬木类 `metallic = 0.0, roughness = 0.62` 配清晰木纹贴图。
  - **受击表现**：刚性碰撞翻滚，无软体缩放形变。
- **软材质（Soft / Elastic / Viscous）**：
  - **轮廓**：饱满圆润球冠、厚实圆环垫圈，绝无尖锐直角。
  - **材质参数**：果冻类采用双层网格（外层 `BaseMaterial3D.TRANSPARENCY_ALPHA`，透明度 `0.58`，光滑高光 `roughness = 0.12` + 内层亮色果核）；硅胶橡胶类采用马卡龙暖粉/亮黄哑光材质（`metallic = 0.0, roughness = 0.86`）。
  - **受击与待机形变**：自带呼吸弹性缩放，受球体撞击或踩踏瞬间触发明显的**果冻压扁回弹动画（Squash & Stretch）**。

### 2.4 与跑道固定一体的刚体专属标识（铆钉锁死法兰底座）
凡是与跑道焊死一体、质量无穷大不可移动的静态刚体（`PinballBumper` 弹球缓冲桩、双岔路中央分流岛墩、漏斗斜挡墙、侧边起飞斜坡、弹簧弹射板基座、护栏立柱）：
- 统一由公共视觉构建器 `TrackVisualBuilder.attach_anchored_flange_base(...)` 在底部与跑道交界处装配**「铆钉锁死法兰底座」**：
  1. 嵌入跑道木板表面的**深灰铸铁法兰底盘 + 黑黄斜纹警示外沿**；
  2. 四角突出 **4 颗银白金属六角螺栓头（Hex Bolts）**；
  3. 独立柱状固定件（如弹球缓冲桩）正面额外印有钢印小字 **`FIXED`**。
- 效果：玩家远远扫一眼底座——**有四角螺丝黑黄法兰盘 = 焊死在轨道上绝对撞不动（借力反弹/上坡）**；**平底直接搁在木板上且印有 `500g`/`20kg` = 有重量的独立物体（可撞动/撞飞）**。

## 3. 模块三：高度方向立体地形、起飞机关与空防博弈

遵循“**飞起来是一种有收益也有风险的主动战术选择**”进行设计：

### 3.1 立体起伏区块与可选侧坡
1. **新增区块 `WaveHills`（波浪过山车滑道，长 `30.0 m`）**：
   - 加入关卡随机区块池（第 1 关起即可刷出）。
   - 由两段平滑衔接的上坡/波峰/波谷木质弧形折板构成（波峰高 `+1.45 m`，波谷低 `0.0 m`）。
   - 低速球沿木轨波浪顺滑起伏；中高速球冲过波峰切线自动腾空飞跃波谷，落地自然触发 `on_land`（激活「震地折射器」与「动量过载」）。
2. **可选侧边起飞小斜坡（`SideLaunchRamp`）**：
   - 在 `StraightWide` 与 `FunnelGauntlet` 区块的一侧（如 `X = -3.0` 或 `+3.0`，宽 `2.4 m`，不阻挡另一侧平地主道），放置带铆钉法兰底座的 `16°` 磨砂亚克力楔形起飞坡。
   - 当平地主道驻守 `20kg` 铸铁大砝码或粘稠减速胶时，玩家可主动侧推切入小斜坡，从重障头顶一跃而过。

### 3.2 桌面起飞机关：`SpringPad`（发条弹簧弹射板）
- **视觉**：底部为铆钉锁死法兰盘，中段为金属螺旋弹簧圈，顶面为亮黄色哑光软胶弹垫（印向上双箭头 `▲▲`）。
- **物理效果**：`Area3D` 触发（冷却 `0.3s`），小球驶入瞬间顶板播放快速弹伸回缩动画，赋予小球**垂直向上起跳速度增量 `Δv_y = +11.5 m/s`**（基于赛道法向）与**前向助推冲量 `6.5 * mass`**，让球高高跃起（峰值离地高度约 `2.8 ~ 3.4 m`）。

### 3.3 空中收益与空中漂浮路障博弈
1. **`AerialBonusRing`（悬空亚克力加速加时星环）**：
   - 布置于 `RampGap` 断桥跳台、`WaveHills` 波峰、`SideLaunchRamp` 及 `SpringPad` 的抛物线航道半空（局部高度 `Y = 2.3 ~ 3.1 m`），外观为细黄铜支杆悬吊的发光青金色透明亚克力圆环。
   - 穿过星环立即获得：**`+0.8 秒` 关卡倒计时** + **`15.0 * mass` 空中前向推进冲量**（并派发 `on_boost_pad` 词条事件）。
2. **`AerialBlocker`（半空漂浮障碍物，防无脑飞天）**：
   - 在半空航道（尤其是星环前后或正中偏置位，随关卡等级提高刷新率）布置**漂浮障碍物**：
     - **前期（第 1~2 关起）**：刷出 `2kg` **漂浮软胶气球桩**（圆润橙粉橡胶球，在半空沿 `X` 或 `Y` 轴做 `±1.1 m` 柔和正弦漂浮）。盲目起跳撞上会被弹偏错失星环，动量达标（`P >= 18`）则可在空中将其爽快撞飞！
     - **中后期（第 3 关起）**：混编刷出 `12kg` **磁悬浮配重铁块**（深灰铸铁方块配底部淡蓝磁浮环，印 `12kg`）。普通球速在空中撞上会大幅失速下坠，迫使玩家在起跳前选好切入角度，或在腾空过程中用 `A / D` 空中侧推灵巧绕障穿环！
