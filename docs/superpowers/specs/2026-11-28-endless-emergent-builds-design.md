## 1. 已确认的体验

用户明确要求：
- 关卡无限增长，不设九关终局。
- 每关严格 30 秒；通过加长跑道提高难度。
- 前五关无构筑、简单操作即可通过。
- 有大致流派，但不能是系统预设好职业或固定套装。
- 单张词条简单，允许看似不利的词条通过组合形成强大效果。
- 强组合应有较长的连续碾压期，之后关卡才逐渐追上。

目标循环：宽松尝试 → 发现相互作用 → 一次强度跃升 → 连续轻松过关 → 距离压力逐渐逼近 → 补强或寻找下一次组合。

保留 Godot 4.6 / Jolt、双键侧推、真实刚体、现有七类积木、球体形状、美术和三维预览。此项目修改局内数值、奖励规则、信息展示、生成预算与验证方法。

非目标：商店、货币、局外成长、装备槽、主动技能按键、固定职业、专属树、指定套装奖励、动态针对玩家构筑加难、新美术风格、无条件永动。

全文具体系数、词条名称和技术拆分属于设计建议；用户确认的是上述体验与规则边界，不冒称其指定了具体系数。

## 3. 必须先修的事实问题

既有源码与临时探针已确认：
1. `PhysicsSynergyBus.rebuild_stats()` 清除初始球 base overrides，领取无关强化也会让重量、半径、弹性、阻尼回到默认值。分离基础底盘与修饰器生命周期。
2. 高弹卡触顶仍进池，静态文案没有体现实际增量。所有候选须先按当前状态计算预览，零收益退出。
3. 用冲量描述收益却不展示除以质量后的速度变化，容易错误暗示“越重所有效果越强”。保留物理差异，但说明必须与计算一致。
4. 场景基础加速很大，容易遮蔽构筑；现有测试只证明多卡比白板快，未验证同次数选卡的作用。
5. 多条碰撞回调和递归事件必须统一去重，不能把引擎回调次数当成动作次数。

先修可信基础，再采集平衡数据。以上属于源码问题；“玩家胜率高”仍需受控仿真与人工试玩验证。

## 4. 无尽流程与严格计时

流程：选球 → 第 n 关（30秒）→ 过线后三选一 → 第 n+1 关；超时 → 结算。n 无设计上限，无胜利状态，无终局选项。

- 第 1 关白板开始；每过一关选一次奖励。进入第 n 关有 n-1 次选择，不额外赠送核心。
- 每关起始 30.0 秒。移除卡牌、星环和所有其他途径加时，不留“先保留接口以后再说”的隐藏续时路径。剩余时间不跨关。
- 倒计时只在 RACING 推进；选卡、起始画面、结算均暂停世界刚体、风、事件冷却、储能释放计时和动画提示。
- 坠落保留现有 1.2 秒拉回等待，期间时间继续流逝，加上实际下落和重跑时间，不额外藏罚秒。
- 每关开始重置能量、事件冷却、配对/接触资格、实体奖励标记；升级与底盘保留。复位也清空储能并抑制构筑触发 0.5 秒，防重复坠落成为收益来源。
- 超时和过线同帧：先扣本帧耗时，再用剩余时间 >0 与有效终点穿越判断成功；<=0 判失败。终点用有限宽高的通行范围或等价扫掠判定，不能在赛道外仅凭 z 坐标成功；高速时不能漏触发。
- 结算表达“到达第 n 关 / 完成 n-1 关 / 本关距离 / 最高关卡”，不出现 n/9 或通关全部章节。

## 5. 距离曲线：线性追赶构筑

初始试验曲线：

```
L(n) = 120 + 20 × (n-1)                 1 <= n <= 5
L(n) = 200 + 25 × (n-5)                 n > 5
```

| 关卡 | 目标轴向长度 m | 30秒所需平均前进速度 m/s |
| --- | ---: | ---: |
| 1 | 120 | 4.00 |
| 5 | 200 | 6.67 |
| 10 | 325 | 10.83 |
| 20 | 575 | 19.17 |
| 30 | 825 | 27.50 |
| 50 | 1325 | 44.17 |

这里平均速度已经包含起步、减速、坠落、绕行等用时，不是仪表盘峰值。表是可调参数，不保证初版这些距离符合白板目标。

原则：
- 先验证无卡前五关，再调 L1、前五关步长和第六关后的固定步长。不得通过赠卡或偷偷加时满足白板要求。
- 第六关后不再随级数提高单位距离障碍密度、物体质量、风强度、窄桥比例或基础设施收益。数量随长度自然增加。
- 不设里程碑长度跳变，不使用指数增长，不按玩家成绩动态改变长度。
- 若有效30秒距离从400m变为650m，25m步长大致形成10关的距离领先；这是解释模型，不承诺每套组合固定碾压10关。
- 引擎仍需要有限安全速度：初版保留现有总速度85m/s防异常，撤掉旧规格32～44m/s软限速。它是工程安全边界，须记录命中率；不得把触顶误认为奖励收益仍完整。
- 85m/s意味着30秒至多2550m的物理上界（实际更低），这是一局可到达距离的限制，不是设置最终关卡。若正常强构筑长期碰到此安全边界，须先做高速碰撞/摄像机/生成测试再提高阈值，不能靠放宽计时延长寿命。

## 6. 关卡生成：长度变，单位路程的规则不暗变

### 6.1 精确长度与生成确定性

- `LevelPlan` 是长度、预算和显示的唯一来源；实际终点对齐 L(n)。不是完整随机块拼到超过 L(n) 然后仍显示目标值。
- 采用完整功能块 + 安全起步/接缝/终点直段补足长度。调整末端直段的长度，不能把跳台/落地区/分岔中途截断；功能物件必须在终点前安全范围内。
- 每关起步和结束有短的安全区域，计入总长。较短关卡优先使用可完整放下的模板；长度算不下的挑战延后到下一块，不削掉落地点。
- 同一等级同版本各种子总长相同，功能类别/资源配额由长度决定；种子只在合法排列、镜像与槽位中变化。完整布局预算与 seed plan 不读取已持有卡。
- 赛道 RNG 与奖励 RNG 独立；区块使用由 run_seed、level、chunk_index、规则版本派生的种子，避免访问顺序影响地图。
- 无尽不等于一次性实例化任意长路线：采用有界前方生成与后方回收，缓冲覆盖当前速度下的生成时延、镜头范围和最大交互半径。完整轻量计划可以按需计算，不能为极大关数预分配海量对象。
- 窗口外不结算玩家相关构筑收益；回收物体脱离交互范围且不可能被回收后重生刷奖。稳定 entity_id 不用实例地址。具体分块大小与缓存结构由实施者决定并测量。

### 6.2 前五关与后续固定配比

前五关按次序介绍转向、轻障碍、起伏/落地、缓冲反弹、分路。所有必经路线对白板可达，给简单操作留出余量；奖励正常发，但测试必须强制无卡复验。

- 不因“教学”要求额外按键。第一关基本中央线可通；后续只需提前轻推转向/对准路线，允许少量撞击。
- 前五关不投放必须借构筑才能跨过的缺口；不叠加无护栏窄桥与强侧风。重物可绕过，跳台有安全替代路线。
- 第五关时各常规机制已可见；第六关以后保持同一块池/质量档/风档/单位密度的目标配比。为长度离散取整造成的小幅配额变化不算主动加密。
- 每段可选起跳点必须有可达落点；高空奖励有真实入口和返回地面通路。空中线是效率选择，不是硬门票。
- 相邻块组合需校验安全接缝和入场速度范围，避免随机拼出必须瞬间180度变向的路线。

第六关以后每100m的初始目标预算（在整关按余数分配，不每块重复向上取整）：

| 对象/机会 | 每100m起始预算 | 说明 |
| --- | ---: | --- |
| 可推动轻/中障碍 | 6个 | 同关按约2:1轻/中分配；推动后可形成连锁 |
| 可绕行重障碍 | 1个 | 质量档固定，不随关增长 |
| 有效起跳—落地点 | 2处 | 每处都能由默认球使用 |
| 固定缓冲桩 | 1个 | 普通护栏反弹机会另外自然存在 |
| 加速带 | 1个 | 固定基础推进 |
| 空中星环 | 1个 | 无加时，只有推进 |
| 爆炸桶 | 1个 | 可由玩家、碎片或风触发，但来源归属有区别 |
| 风区 | 1个 | 同关风型按固定比例配额；强度/长度不随关增加 |
| 粘液区 | 1个/200m | 始终留可绕路线 |

前五关用同一档物体与不高于此密度的教学模板。第六关不因切换模板骤增负担，基准检查第5→6关用时变化是否主要来自25m增量。

基础推进起点：加速带 +4m/s；星环 +2m/s；缓冲桩附加前向 +2m/s；爆炸桶近处 +3m/s，随距离衰减。保留真实法向反弹和爆炸物理效果；这些基础推进以 `J=m×Δv` 保持底盘间相同标称提速。每个实体的基础推进每关只兑现一次，不影响真实碰撞或卡牌有效反弹重复触发。

风仍对所有真实刚体施力；风向、强度和覆盖长度的每100m预算均受控。通过多种子白板实验，确认更多设施只是维持相近的基础平均效率，不会让白板因路程更长而自行形成不断加速的免费循环。

## 7. 底盘与属性：可解释的真实差异

保留现有三个形状、外观与预览。首版把每种形状的大幅随机物理数值收敛为固定模板，外观仍由种子变化，以便判断差异来自构筑还是开局随机值。

| 底盘 | 质量kg | 半径m | 弹性 | 摩擦 | 阻尼 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 圆球 | 1.5 | 0.55 | 0.30 | 0.42 | 0.32 |
| 橄榄球 | 1.4 | 0.55 | 0.40 | 0.42 | 0.32 |
| 圆边滚筒 | 1.7 | 0.55 | 0.25 | 0.42 | 0.32 |

各形状沿用真实几何差异；不绑定任何词条。基础模板整局持久，只有新局选球才能替换。

- 卡牌改变属性用加算增量，不再重复叠乘百分比造成指数失控。
- 物理属性有安全/可读边界：质量0.6～8kg，半径0.40～0.95m，弹性0～0.95，普通线性阻尼0.08～0.60，空中重力倍率0.5～2.4，空中侧推系数0.65～1.0，卡牌波半径最多12m。
- 达上限的相应升级退出池。部分触顶时显示并保存真实施加增量，不保留越界隐藏数值。例如质量7.9kg再加0.3kg，只获得0.1kg；以后减重不会先抵消看不见的0.2kg。
- 相反属性卡可以同时出现，玩家可以改变方向；不回收过去的选择。所有选择记录包含名义与实际施加增量，重算/回放可重现。
- 事件卡明确区分固定冲量、速度转化和对外作用；不是所有效果都用 `J=m×Δv` 标准化。固定冲量对轻球提速更多，重球则在撞开物体与对外冲击上有优势。

## 8. 首版15个原子词条

分组仅帮助阅读，不是职业或前置树。不设核心、稀有度强弱分层或套装奖励。

记 r 为持有等级，S(r)=sqrt(r)，r从1开始。事件卡采用S(r)提高已有公式的系数，可重复升级且不设等级上限；同卡边际递减，新规则交互仍可造成跃升。实际候选若因安全边界使所有效果完全不变，应退出池而不是出售空等级。

### 8.1 六个物理属性词条

| ID / 名称 | 每次名义效果 | 直接代价或限制 |
| --- | --- | --- |
| `ballast` 配重块 | 质量+0.3kg | 固定冲量/风对自身加速变小；真实撞击更有力 |
| `light_shell` 轻质外壳 | 质量-0.2kg | 更易被障碍撞偏，对外冲击变弱；风和固定冲量收益更大 |
| `elastic_skin` 高弹外皮 | 弹性+0.10 | 更容易偏离地面路线；不直接保证更快 |
| `wide_shell` 膨胀外壳 | 半径+0.04m，质量不变 | 更易碰到障碍、迎风面积变大；波范围不自动因球半径增大 |
| `heavy_fall` 下坠配重 | 空中重力倍率+0.20 | 更快落地，最高处与腾空时间减少；不改变地面重力 |
| `low_drag` 顺滑表皮 | 普通阻尼-0.04 | 保速更好；不免疫粘液，也不附带额外固定推进 |

有利/不利随环境变化；文案不把重量或弹性显示为一条“越高越好”的战力条。

### 8.2 六个事件转化词条

以下公式是初始标定点。v_down=落地前沿跑道上方向的下降速度；v_normal=碰前相对法线接近速度；v_hit=有效冲撞时玩家接触前总速度；m=玩家质量。卡牌造成的冲量/冲击波均与真实物理结算分层。

| ID / 名称 | 单一主要规则 | 初始公式 |
| --- | --- | --- |
| `landing_drive` 落地折射 | 有效落地时把下降运动转为前向推进 | J=0.35×m×v_down×S(r)，故同落速自推Δv与质量无关 |
| `landing_wave` 震地膜 | 有效落地产生向外冲击波 | 中心冲量J=0.50×m×v_down×S(r)，基础半径3m，作用于周围刚体 |
| `rebound_drive` 反弹折射 | 有效反弹产生前向推进 | J=0.45×m×v_normal×S(r)；使用实际法线速度，不再用总速度保底 |
| `impact_drive` 破障喷口 | 每次有效破障得到固定前向冲量 | J=6 N·s×S(r)，轻球提速更明显 |
| `impact_wave` 破障震波 | 每次有效破障在该目标处发出冲击波 | 中心冲量J=(4+0.15×m×v_hit) N·s×S(r)，基础半径2.5m |
| `loss_cell` 损耗电容 | 首次撞击不同障碍时，按自身平动能减少量充能；下一次有效落地或反弹释放为前向动能 | 充能系数η=0.60；容量C=60J×S(r)，释放后清空 |

电容没有第二张必需“释放卡”，单独也能工作。容量增长不提高充能系数。这里的储能是额外生成的玩法奖励，不声称回收碰撞双方系统的真实耗散；玩家把能量传给箱子或由平动转成自转时，也允许按下面的明确定义充能。所有“守恒/不制造能量”的表述均不适用于此卡，防循环靠有限目标资格。

充能契约：
- 仅玩家直接撞到可移动障碍（轻/中箱、球瓶、史莱姆、可碰的重物；不含爆炸桶）且相对法线接近速度>=3m/s有资格。无需已持有破障卡，也无需把重物撞开。护栏、地板、固定缓冲桩不充能。
- 每个稳定目标ID每关只允许一次充能尝试；第一个合格接触即消耗资格，无减速或容量已满也消耗，避免重复借同一运动物体刷能量。此集合独立于破障奖励集合。
- 一个物理步最多进行一次充能结算：若有至少一个本步首次合格目标，将全部这些新目标标为已尝试，计算 `D=max(0, 0.5*m*(|v_contact_before|²-|v_contact_after|²))`，增加 `min(0.60*D, C-E)`，不能按目标数重复乘D。这是本步玩家自身平动能减少，不是两物体系统耗散，不计转动能。
- before/after必须取卡牌自推、储能释放、桶/缓冲桩脚本推进之前的真实接触边界快照。用该步接触冲量重建边界时须在Jolt控制场景中验证；不可靠时本步不充能并记诊断。不能用上一帧到本帧的总速度差把阻尼、风、坠落归零、复位归零或速度保护裁剪当成接触损失。
- 同步多接触不拆分能量归因：只按本步一次D计账，即使还接触了地面。规则明确不宣称这份减少全部由新目标造成；新合格障碍只是本步充能门票。来自单一静态表面或旧目标的接触不能独自再次充能。

电容释放：只有当前前向速度>=0时释放，将前向速度改为 `sqrt(v_forward² + 2E/m)`，保留横向/竖向分量，消耗全部储能E；逆行时保留余额，等待下一次满足条件的有效落地/反弹，不免费翻转方向。显示实际速度变化。多个同帧释放条件只使用事件开始前的余额一次；若同帧又撞上新障碍，先释放旧余额，再加入本步合格新目标带来的充能，不能即时收即放。复位/换关清零。

### 8.3 三个通用修饰词条

| ID / 名称 | 效果 | 适用范围 |
| --- | --- | --- |
| `external_sail` 借力帆 | 有利场景外力系数=1+0.15×S(r) | 加速带、星环、缓冲桩基础推进、桶的基础推进，以及风的前向/上升正分量；不放大卡牌自身推进 |
| `wave_lens` 扩散膜 | 卡牌波半径系数=1+0.20×S(r)，最终半径<=12m | 只扩范围，不同时增加中心冲量；无发波能力时不进入池 |
| `air_steering` 空中舵 | 每次空中侧推系数+0.10，上限1.0 | 更好控制落点，不自动产生前向推进 |

`wave_lens` 用能力标签 `emits_wave` 判断资格，不指定必须拥有哪个卡ID。其他14张不需要某张指定卡；部分卡的作用依赖赛道动作，但前五关内已提供对应机会。

## 9. 组合为何会自然出现

这些是验证用交互案例，不是程序套装判定，也不在UI直接标成必选攻略：

1. 高弹外皮 → 更多有意义的再次腾空 → 落地折射收益；空中舵帮助控制落点。弹性本身仍可能损失路线效率。
2. 下坠配重 → 同等起跳条件下改变下降速度与落地时机 → 震地膜/落地折射的输入变化。是否净变快由真实轨迹验证，不保证每个跳台都更强。
3. 配重块 → 更容易直接撞动障碍、震地对外冲量增大 → 更多破障 → 破障喷口/震波。更重也让喷口的固定J转为较小Δv，形成真实取舍。
4. 轻质外壳 + 借力帆 → 风场响应更强；轻质 + 破障喷口 → 单次Δv更大，但撞开较重物体更困难。
5. 震地膜/破障震波 → 推动物体 → 再触发有效破障 → 喷口推进或继续震波。规则允许跨不同目标传播，不依赖预置三件套。
6. 损耗电容 + 有效反弹/落地 → 把先前撞击不同障碍时的减速换成推进奖励；通过寻找新障碍获得充能，不是反复撞同一表面就能无限增能。

只要遵守公共事件，未来词条也能加入这些链路，不需修改其他卡的ID列表。

## 10. 事件来源、连锁与防重复契约

### 10.1 公共事件

至少携带：稳定entity_id、root_event_id、physics_tick、source_kind（玩家直接/玩家衍生/纯环境）、父事件、玩家接触前快照、目标速度、接触法线、碰前/后速度、是否复位抑制。事件观察与奖励统一入口，禁止多个物理回调各发一次收益。

- 有效落地：真实承重接触，连续腾空>=0.40秒，v_down>=3m/s，每段腾空最多一次；全局冷却0.60秒。微小接触抖动不重置腾空周期。
- 有效反弹：护栏或固定缓冲桩，法线近水平（abs(dot(normal,up))<=0.35），v_normal>=2.5m/s，碰后法线速度朝离开表面；全局冷却0.40秒；同实体连续离开接触>=0.15秒后才可再次触发。地板和可移动杂物不计此事件。
- 有效破障：可移动目标首次被玩家或可归属玩家的衍生作用解锁，并沿地面方向获得至少1.5m/s的实际或已排队施加速度变化。默认参与者为轻/中木箱、球瓶、可解锁史莱姆；铁砝码/锁定铁块不发破障收益。目标不必销毁，仍保留真实刚体。
- 每个可奖励目标一关仅发一次破障事件；可视解锁但未达到阈值时不先消耗资格。环境先使其解锁则永久标为环境来源，本关不再改认玩家破障，防捡已倒目标刷收益。
- 同物理帧两来源竞争同目标：先采样真实玩家接触，再结算由本帧新事件派生的波；同一阶段按稳定entity_id顺序。只有首次满足条件的来源拿到归属。不能取决于容器遍历顺序。

### 10.2 连锁允许跨目标，禁止同目标自循环

- 玩家波或玩家归属的移动碎片可传播玩家归属；桶若由玩家/已归属碎片/玩家波引爆，其后续作用也可归属玩家。纯风先吹动的物体和纯环境引爆不凭空变成玩家动作。
- 玩家归属运动体记录最近真实玩家推动/已归属碰撞的根事件；超过2秒无此类更新即过期，或速度低于1m/s持续0.3秒即清除。同一实体的破障奖只发一次不受归属更新影响。
- 传播强度使用实际作用，不能拿初始玩家高速快照无限套给后续所有目标。衍生破障事件中的v_hit由本次目标获得的速度变化换算并限制不超过根事件玩家v_hit；m使用当前玩家质量。具体事件字段需明确保留direct和derived来源。
- 移除旧 `MAX_CHAIN_DEPTH=3` 对正常不同目标链路的截断。采用广度事件队列逐帧处理，避免同步递归爆栈；每个波对同目标最多作用一次，每个目标一关最多计奖一次，因此有限场景内链路有限。
- 每物理帧最多处理64个衍生事件，超出排队到下一物理帧；不静默丢弃奖励。因关卡退出/复位被取消的待处理事件记录取消原因。帧预算仅限计算调度，不是可重复刷新的奖励额度。
- 连锁队列中的世界位置与可用目标由发生时快照/稳定ID确定；已回收或无效目标安全取消，不复活实体。

### 10.3 收益顺序与安全边界

每物理步顺序：真实物理完成并保存接触边界快照 → 归一事实与去重 → 对旧储能生成释放意图并清旧余额 → 按快照向电容加入本步新充能 → 收集其他卡牌/场景收益意图 → 按稳定顺序施加 → 执行/排队衍生波 → 记录实际收益。多个同帧释放条件最多释放一次旧余额。所有意图计算读取同一个动作快照，不以脚本回调先后改变输入。

- 卡牌自推使用其公式计算J，再除以实际质量；场景固定Δv使用J=mΔv。说明和预览不得混淆。
- 沿用85m/s总速度安全限制，并设置每物理步所有额外自推合计最大+45m/s的异常保护；旧“每次dispatch各有45”改成统一按步汇总，不能通过多个事件绕过。
- 不设32～44m/s软上限。被安全边界裁掉的收益归因到来源日志，奖励页显示可能受限；典型强构筑若经常触限，作为工程/平衡问题处理，不能宣布成长顺滑。
- 波对每个目标施加向外并略向上的冲量，按距离线性衰减到边缘0；不直接改成销毁目标。沿用碎片32m/s速度保护，卡牌波最大12m作用半径；边界必须进入预览和诊断。
- 调参不通过给所有卡统一低收益硬帽消灭连锁爽感；先查重复计奖、免费场景循环和根事件来源错误。

## 11. 无限局中的抽卡与重复成长

- 第1关起每关结束均三选一，没有固定核心屏、职业标签、改造解锁层或第九关特殊行为。
- 每张属性卡按当前状态计算实际变更，已触边界/实际增量为0退出；放大器按能力可用性过滤。不会生成“拿了也完全不工作”的纯前置卡。
- 候选至少有一个当前能工作、无新增物理负面且不依赖未拥有机制的选项，例如落地折射、反弹折射、破障喷口、顺滑表皮、借力帆、空中舵；资格还需符合下一关的固定机会计划。其他两项可为物理取舍、重复升级或另一种机制。
- 不依据推断流派保障某套配件，不显示最佳答案。每个合格ID基础权重相同；已有ID与新ID同权，首版不引入稀有度。先抽保障项，再从其余合格ID无放回抽两项，最后独立RNG打乱显示顺序。
- 普通无上限事件卡保证正常可达长局不会因物理属性全满而无卡可选；测试至少覆盖合法100次选择的抽卡序列和全物理属性触界状态。
- 极端浮点精度/安全饱和导致不足三项时只显示真实有效数量，允许“保持构筑，继续下一关”作为明确兜底，不塞零收益假卡。正常前50关不应触发该兜底；触发则报诊断。
- 记录规则版本、种子和选卡顺序；同版本同历史确定性复现。同种子不同选择可改变未来奖励资格，不改赛道。
- 无装备槽上限、无替换费用；重复卡显示“等级r→r+1”和实际增量。相反属性允许主动纠偏，但不回退选择次数。

## 12. 奖励信息：解释确定关系，保留发现空间

默认卡片：名称 / 当前等级 → 下一等级 / 单一规则 / 当前具体变化 / 一条代价。详情展开触发阈值和物理解释，不把公式堆在主卡面。

示例（只演示表达；显示值必须按实际状态算）：

```text
轻质外壳 · 等级1 → 2
质量：1.5 → 1.3 kg
同样的风力下，加速度提高约15%
已有「破障喷口」单次提速：4.00 → 4.62 m/s
代价：更容易被障碍撞偏
```

动态预览只展示确定可推导的单次结果：
- 固定冲量按当前/预览质量除算。
- 落地/反弹用相同标准事件（落地v_down=8m/s，反弹v_normal=4m/s）比较，并清楚标“示例条件”；已有近期实际事件时可另显示历史值，但不承诺复现。
- 属性变化可影响多种卡，主面最多列两条确定联动，详情查看全表；不列“风帆流必选”“总战力提升”。
- 累计冲量/Δv不是最终速度，不写“上一关加速总计30m/s，所以现在更快30m/s”。
- 历史显示本关有效触发次数、实际卡牌贡献、空触发与被保护裁剪次数；不虚构每卡节省几秒或预计通关概率。
- 不能因预览调用而修改真实属性、储能、RNG或持有等级。

HUD：第n关、30秒倒计时、实际剩余轴向距离、速度；储能条仅持有电容时出现。触发提示用实际收益和来源，合并密集连锁如“连锁破障×5”；避免同时刷几十条浮字。主要信息不再突出全局乘区/动能。

奖励页顶部显示本关耗时、余时、坠落、完成距离、下一关长度与增加量，提醒玩家是路程追赶。失败结算显示已过关数、失败关完成率、种子、底盘、词条与最近几关效率变化。

保留现有风格、鼠标与键盘操作，1280×720可读。展开说明须可用键盘访问，不能仅依赖hover或颜色。

## 13. 实现职责与旧系统退场

- `RunState`：无尽关号、严格30秒、选卡历史、失败统计；删除加时语义与九关概念。
- `StatSheet`：持久基础底盘、已实际施加的属性增量、明确边界、无副作用预览；质量/形状变化同步刚体与视觉。
- `UpgradeDefinition/Catalog`：15个定义、属性实际增量、事件级数函数、能力标签、当前资格、统一预览；不保留旧稀有度/核心树。
- `PhysicsEventContext/Bus`：归一事件、稳定来源归属、一次性奖励、队列与储能；不能把ID套装特判藏入总线。
- `PlayerBall3D`与实体：真实物理事实、首次解锁、玩家归属传播、固定场景收益、统一自推保护；需要合并已有多回调路径。
- `LevelPlan/TrackGenerator`：精确总长、每米预算、教学模板、常规配比、有界实例化；UI共用长度来源。
- 统计：按关记录起步/完成/超时、进度、坠落、每类机会与动作、实际收益/能量收支、保护命中、队列峰值；不要求UI展示全部诊断。

旧12卡退出活动池，包括续时、全局过载、转化双次结算。可复用资产与底层函数，但不保留隐藏效果以迁就旧测试。当前没有旧局存档兼容承诺，不实现迁移；规则版本变化后不承诺旧种子同路线/同卡序列。

新旧设计冲突时以本文和后续用户决定为准，README与现有说明中的30秒加时、12张旧卡、职业核心/九关字样须在实现时同步修订。

## 14. 验证：先证实白板，再证实涌现与长局

### 14.1 自动化行为契约

1. 初始球属性不因无关升级被清除；相反属性、部分触界、重算和预览一致，越界量没有隐藏债务。
2. 三种底盘任何卡都不被职业锁定；单卡公式、重复级数、能力资格、零收益过滤与同种子结果可复现。
3. 所有旧加时路径均移除；环、波、连锁、卡牌任何事件不能让本关超过30秒；暂停与坠落计时符合规则。
4. 有效落地/反弹/破障阈值、重复回调、同目标多波、贴墙、复位、环境归属、队列跨帧与取消均正确。
5. 电容单步充能不超过定义的玩家平动能减少D×0.6与剩余容量；同事件不收即放；同目标只尝试一次，多目标同帧只结算一次D；静态表面和旧目标不充能；逆行不免费翻转；换关/复位清空。有限固定目标集不能通过重复碰撞无限充能。验证玩家能量转给箱子和转为自转时的行为符合定义，不做碰撞系统能量守恒断言。
6. 连锁可超过3个不同目标，且同一目标一关仅计奖一次；环境先动目标不补发；两个卡通过公共事件联动，无额外套装代码。
7. 统一速度保护不能被多次dispatch绕过；贡献记录合计匹配实际施加量。
8. 第9→10、49→50、99→100以及极高关数的长度/状态计算无终局分支，无关号上限；生成内存不与整个极长关卡的实体数量线性无界增长。
9. 精确终点、块接缝、预算配额、实际UI距离、高速扫掠过线；不同选卡不影响布局。大批种子检验合法结构。
10. 无限升级的候选不足兜底明确且不会阻塞下一关；正常前50关保持三项有效选择。

### 14.2 关卡与构筑实验

开发集20个固定种子、保留验收集30个；先使用固定圆球控制变量，再复测另外两种底盘。引擎版本与规则版本写入报告，物理轨迹跨平台不承诺逐位相同。

A. 前五关白板：
- 强制不装任何卡，分别完整跑1～5关。使用简单操作策略：维持车道、提前避开重物、选择地面安全线，不追逐奖励或使用高级反弹技巧。
- 初始诊断目标：每关成功率>=95%，中位余时>=6秒；另做一次轻碰撞/小幅转向迟误的容错场景。此为待验证目标，不当作已达成事实。
- 失败样本必须回放区分卡死、非法拼接、控制代理能力不足和时间过紧；不因某个自动策略失败就一律削弱关卡。

B. 单卡与交互：
- 同地图/底盘/操作策略比较A、B、A+B及等次数无关卡；保持选卡次数相同，不能用多拿卡解释组合强。
- 为第9节至少三个不同交互验证，给出单卡带来的损失/收益和组合后有效行进距离的变化。涌现不要求每个种子都超加算，但必须存在可复现的条件且不是实现漏洞。
- 负面属性必须记录物理后果；如果组合只在文案成立、真实轨迹不成立，改规则或删除，而不是写套装补偿。

C. 长局与爽刷期：
- 比较随机合格选卡、重复堆单一卡、基于实际机制选卡三类策略；全部每过一关只选一次，使用相同种子机会、底盘和固定操作策略。
- 统计到达关分布、每关余时/完成率、单位距离用时、发现组合前后距离能力跃升、连续宽松通过的关数，以及高阶保护命中率。
- 将“宽松”暂定义为余时>=6秒；在代表性的有效强组合上，以组合形成后连续约5～10关仍可宽松通过作为调参参考，不保证所有组合都获得相同期限，不通过动态关卡修改来保证。
- 冻结构筑的单独对照用于测量一次突破本身领先多久；真实长局仍正常领取奖励，两组不可混报。
- 后期白板/弱构筑自然追不上长度，但不是通过增密、重物升级或减时间造成。关5→6与9→10不得出现额外隐性跳变。

D. 人工试玩与交付：
- 至少先找首次接触与熟悉操作两组，各3人用于发现问题，不宣称统计显著。观察前五关白板、选卡理由、负面词条理解、是否自主发现组合、强势期是否足够长。
- 没有真人测试就明确标为未完成，不用代理替代体验验收。
- 保留物理与几何回归，更新已改变规则的测试；桌面渲染检查选球/奖励/连锁/储能/超时；Web构建与实际主要流程冒烟检查。
- 交付版本化奖励表、距离参数、基准报告和未完成验证项，不以“单元测试通过”替代平衡结论。

## 15. 实施顺序与授权边界

这是一个跨规则、物理事件、UI与生成器的改造项目：
1. 底盘生命周期、严格计时、事件归一、统计；先复验白板。
2. 原子词条与预览、连锁归属、电容、无尽抽卡；复验交互。
3. 精确长度与单位预算、有界生成、长局基准、UI与Web回归；校准强势期。

上述顺序不代表可把任何一阶段当作整个请求完成。每阶段保持可启动游戏；可用内部测试开关隔离开发，但最终只提供一套玩家规则。

具体文件拆分、数据资源格式、队列容器、生成窗口尺寸、UI控件排布、自动操作策略实现由实施者选择；改变用户确定的无尽、30秒、长度主难度、前五关白板和自由组合需回到讨论。平衡系数允许按报告调整，不需逐次请求用户确认。
